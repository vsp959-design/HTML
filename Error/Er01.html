Error 01

24.07.26 совершил ошбку при решении создать новый директорий "Github" и потратил на поиск ошибки более 3-часов:

Заметил странное поведение Web-сервера: Вышеобозначенная Ссылка - то открывается, то - нет. Причем, открывается только через приложение "файлы" при переходе на браузер. Далее, если вернуться по ссылке "домой"(на стартовую страницу), a затем на страницу Github.html, - перехода по этой ссылке на страницу Gh01.html не происходит. Не происходит перехода по этой ссылке и после загрузки сайта с начальной страницы через Web-сервер. Но переход происходит между этой ссылкой и вышестоящей страницей Github.html многократно, если загрузиться через приложение "файлы" и перейти по ссылке на браузер. И еще, я заметил, что Web-сервер перестал реагировать на изменения, вводимые в редакторе Kodex на станицы сайта.
После остановки и нового запуска Web-сервера, Сайт открыл страницу Github.html в старой редакции. Где он ее взял - неизвестно, в Приложении "файлы" - открывается уже новая редакция?! < br> Через 2 часа - похоже я нашел ошибку: в другом директории Page хранился аналогичный старый файл Gethub.html а головной странице была указана ссылка именно на него. ВЫВОД : Нужно быть очень внимательным при любой модернизации сайта!
Но суть ошибки и ее последствия в другом - Я использовал механизм "ветвления", думая, что создаю новые директории в корневом директории и заполняя их файлами своего сайта.
Но создание директория в корневом каталоге сайта осуществляется по другому: - новый директорий создается в момент создания нового файла в указанном директории путем указания имени нового директория перед символом "/", который ставится перед наименованием файла. Новый файл может быть пустым и служить только цели создания нового директория, и в последующем может быть удален. О любое удаление Github не очень то любит и лучше этого не делать, а выбрать одно и то же имя для всех таких файлов-пустышек и стараться испооьзовать только его, чтобы не запутаться и плодить мусор.
Вообще программа Github предназначена для версирования ПО и сшивания этих новых версий. Как это осуществляется - буду изучать.
