Программирование в HTML и CSS

На этом сайте я, спустя почти три года, начал восстанавливать свои старые знания о HTML и пополнять новые, поскольку появилась потребность освоить новый для меня инструмент формирования заметок, статей и записей взамен OneNote от Microsoft, который стал проявлять себя с задержками, сбоями расположения страниц в окне OneNote и уже устаревшим сервисом.
Инструмент OneNote хорош для быстрой фиксации информации. В новом же инструменте я хочу отобразить с помощью ссылок систему быстрого поиска и доступа к необходимой информации, чего нет в OneNout. Поэтому новый инструмент должен быть более полезен в создании Справочников.
Посмотрим, что из всего этого получится.
Хочу сразу сообщить, что в этом проекте я использую Ipad, для этого мне пришлось установить из Apstore редактор Kodex и Web-сервер WorldWidedWeb. За основу своего нового курса HTML я взял книгу В.Дронова «HTML 5, CSS 3 и Web 2.0», 2010 г.
Примеры кода и демонстрации из этой книги с моими пояснениями я размещу в отдельных ссылках на странице "В.Дронов - код и примеры"
