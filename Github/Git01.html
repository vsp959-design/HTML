Инструкция Kimi

Шаг 1. Подготовь сайт
Убедись, что у тебя есть готовые файлы сайта (HTML, CSS, JS, изображения и т.д.). Главный файл должен называться index.html — это точка входа.

Я все исправил, потому что у меня главный файл назывался иначе.Заодно, я заметил, что теперь при открытии в Web-сервере головного каталога сайта - сразу открывается стартовая страница сайта, что создает неудобства, если ты хочешь просмотреть какой-то другой файл в директории сайта.


Шаг 2. Создай репозиторий на GitHub
Зайди на github.com и авторизуйся.
Нажми New (зелёная кнопка «+») → New repository.
Введи имя репозитория (например, my-site). (Я назвал HTML5)
Оставь публичным (Public) — иначе GitHub Pages не будет работать на бесплатном тарифе.
Нажми Create repository.
