Коротко о Github

Для того, чтобы обеспесить доступ к сайту другим пользователям (друзьям и знакомым) я обратился за советом к чату Copilot, установленным у меня на Ipad. И получил ответ, что Ipad не позволят организовывать внешний доступ к своим файлам и на сегодня один из лучших способов - это разместить сайт на Github, который лучше всего установить через App Store на Ipad.
На мой сайт в Github доступ будет открыт только по ссылке (для друзей), но предварительно нужно установить в шапку сайта ограничения для поисковиков. В Github также есть возможности версирования, возможности для хранения многовариантности сайта и его обновлений.
