Примеры и коды из книги В.Дронова

В этом разделе сайта я буду отображать некоторые интересные факты и примеры из книги В.Дронова «HTML 5, CSS 3 и Web 2.0», 2010 г. Коды из книги В.Дронова будут публиковаться по ссылкам ниже с такой же нумерацией, как и в книге.

Структурирование текста в html происходит с помощью разбиения текста на блоки - абзацы. Каждый блок выделяется тегами, например <p>...</p>.

Я проверил: между абзацами вставляется небольшое разделение по строкам, и сверху и снизу абзаца, отступа с новой строки я не заметил. В качестве обозначения тега абзаца, видимо, может использоваться любая буква, или текст на английском языке, кроме служебных, использующихся для обозначения тегов (a,b,q,...u ...), но в этом случае разделения по строкам не происходит.

В книге В.Дронова в Гл.6 описаны методы программирования перехода по гиперссылкам с помощью горячих клавиш и атрибута ACCESSKEY, а также метод определения направления обхода гиперсссылок с помощью атрибута TABINDEX. Также там описаны методы вставки на Web-страницу графических гиперссылок, изображений карт с "горячими" областями, полос навигации по сайту.
