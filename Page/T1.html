Тег <META>

Тег <META> - одинарный метатег и, как уже говорилось выше, предоставляет часть метаданных о документе HTML для браузера, поисковиков и соцсетей. Пользователь не видит содержимое метатегов на странице.
Тег <META> размещаются внутри тега <head>. Тегов <META> может быть много.

Тег <META> может содержать следующие метатеги:
charset - указывает на кодировку страницы, и который используется без связанного атрибута "content", в отличие от других метатегов. Чтобы избежать ошибок кодировки, необходимо уместить метатег с атрибутом charset в первых 1024 байтах документа;
http-equiv - указывает, что страница должна быть отправлена вместе со следующими данными:
Content-Type- HTTP-заголовком. Такой заголовок указывает браузеру или другой программе тип отправляемого документа, который указывается через связанный атрибут "content";
При разработке HTML первоначально предполагалось, что веб-серверы будут считывать метатеги внутри отправляемых клиенту веб-страниц, и формировать HTTP-заголовки в зависимости от их содержимого, на практике это не реализовано в наиболее используемых веб-серверах, соответственно, веб-серверы не меняют отправляемые клиенту HTTP-заголовки, а клиент (веб-браузер) обрабатывает эти метатеги самостоятельно(в частности, данные из метатегов могут заменять данные, получаемые из HTTP-заголовков. Википедия.
default-style - предпочтительный стиль таблиц, который используется на странице. В этом случае в атрибуте content прописывается заголовок из элемента <link>, который связан с таблицей CSS-стилей, или заголовок элемента <style>, который содержит таблицу CSS-стилей.
refresh - время автоматического обновления страницы. Страница будет автоматически перезагружаться с интервалом, который указан в секундах. С помощью атрибута http-equiv="refresh" можно сделать так, чтобы страница отправляла пользователя на другую страницу через определённое количество секунд. Например, отправим пользователя на главную Яндекса через 15 секунд: <meta http-equiv="refresh" content="15;url=https://www.yandex.ru">

content - указывает содержание связанного атрибута.
Например, <META HTTP-EQUIV="Content-Type" CONTENT="text/html">, где в HTTP- заголовке страницы должен быть указан тип содержимого "Content-Type" co значением "text/html".
На страницах нашего сайта используется тег <META HTTP-EQUIV="Content-Type" CONTENT="text/html; charset=utf-8">, где в HTTP- заголовке страницы должен быть указан тип содержимого "Content-Type: text/html" и через "; и пробел" указан новый метатег "charset=utf-8", что, видимо, допускается правилами HTML.

name - указывает метатег со связанным атрибутом content
стилей.
keywords - ключевые слова, которые помогают поисковикам находить страницу в интернете. По сути, это самые важные слова из содержания страницы. Hапример: <meta name="keywords" content="википедия, энциклопедия">
description — краткое описание страницы, которое видит пользователь, когда находит сайт в поисковике. Например: «рассказываем, как нарезать картошку тонкими ломтиками» для сайта о кулинарии. Это описание помогает поисковикам найти страницу, а пользователю — узнать, о чём она.
Если хочется контролировать, что именно увидит пользователь в поиске — всегда следует заполнять description, поскольку поисковик выдаст ваше краткое описание к результату поиска, а если его не заполнить, то поисковик может выдать "свое" содержание.
author - имя автора, что также облегчает работу поисковикам
format-detection - ограничение отображения формата. Например: такой браузер, как Safari, очень любит подстраивать номера телефонов в какой-то удобный для себя вид. Чтобы отключить это своеволие, нужен отдельный метатег: <meta name="format-detection" content="telephone=no">
viewport - задаёт параметры окна просмотра в браузере. Страницу можно сделать адаптивной, подогнав ширину окна под размеры устройства. В примере ниже width указывает ширину окна просмотра, а initial-scale — коэффициент масштабирования страницы при первом открытии: <meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=2.0, user-scalable=yes">

С помощью метатегов можно задавать поведение мобильной версии сайта. Например, можно прописать, на сколько на мобайле можно увеличить масштаб и насколько уменьшить относительно стандарта.
Через метатеги задаётся и Open Graph-разметка: заголовок, картинка и описание для репоста в соцсетях.
