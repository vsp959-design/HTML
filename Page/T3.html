Теги списков

Списки бывают упорядоченные и маркированные.
Для упорядоченного списка используется парный тег <ol> (ordered list), внутри которого тегами <li>...</li> обозначается содержание элемента списка.
Тег <ol> имеет атрибуты:
type, который устанавливает тип нумерации:
  • A — заглавные латинские буквы;
  • a — строчные латинские буквы;
  • I — заглавные римские цифры;
  • i — строчные римские цифры;
  • 1 — арабские цифры.
start - обозначает число, с которого начинается нумерация;
reversed - меняет направление нумерации:
Тег <ol> также поддерживает все глобальные атрибуты.

Для маркированных списков используется парный тег <ul> (unordered list). Сами пункты списка размечаются при помощи тега <li>.
В предыдущих весиях HTML до HTML-5 в теге <ul> присутствовали два атрибута, которые уже с версии HTML-5 не поддерживаются. Все остальные регулировки в списках в HTML-5 осуществляются с помощью CSS.

Есть общее правило для всех списков: Все списки могут быть вложены друг в друга, не зависимо от типа.

Еще HTML позволяет создать так называемый список определений, представляющий собой перечень терминов и их разъяснений. Такой список создают с помощью парного тега <DL> (definition list). Внутри него помещают пары "термин — разъяснение", или "ключь - значение", причем термины заключают в парный тег <DT>, (definition term) а разъяснения — в парный тег <DD> (definition description).Для этих элементов доступны глобальные атрибуты.
Cписки с <DL> обеспечивает семантически правильную структуру, которую поисковики используют для метаданных.
