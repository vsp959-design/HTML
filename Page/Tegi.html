Теги HTML

Кодирорвание html основывается на так называемых тегах, специальных символах заключенных в угловые скобки <...>. Каждый тег, за исключением нескольких, имеет тег закрытия , начинающийся с "/" (слэш). Такие теги называются парными. Другие теги называются одиночными.
Всего на текущую дату в HTML5 107 тегов.

Первый тег определяет тип документа - это <!DOCTYPE> — сокращение от «тип документа» (document type).
Так тег <!DOCTYPE html> говорит о том, что публикуемый документ находится в формате HTML.
Следующий тег <HTML> - обозначает контейнер, в котором находится всё содержимое страницы. Это корневой, или родительский, элемент всего документа.
В начале файла HTML отображаются HTML-теги, называемые метатегами, которые задают метаданные.
Mетатеги всегда идут внутри элемента HEAD (Загаловка Web-cтраницы)
В метаданные входит название Web-cтраницы. Оно отображается в заголовке окна Web-обозревателя, где выводится содержимое данной Web-страницы, и хранится в "истории браузера" (списке посещенных к настоящему времени Web-страниц). Название Web-страницы помещается в парный тег <TITLE> и располагается в секции заголовка Web-страницы.

Тег <META>- одинарный тег - предоставляет метаданные о документе HTML. Мета-элементы обычно используются для указания описания страницы, ключевых слов, автора документа, последнего изменения и других метаданных. По этой ссылке находится более подробное описание <META>.

Кроме атрибутов относящихся к отдельным тегам в HTML присутствуют глобальные атрибуты, которые могут быть применимы большинством тегов.


Важные на мой взгляд теги:
<!-- …….-->- тег комментариев;
<a> - тег ссылок;
<strong> - тег полужирного шрифта с нажимом на важность;
<b> - тег полужирного шрифта без нажима на важность;
<еm> - тег курсива;
<i> - тоже тег курсива
<br> - тег переноса строки
<wbr> - (от англ. word break — разрыв слова) указывает браузеру место в слове для переноса строки, если перенос требуется браузеру;
<hr> - горизонтальная строка;
<mark> - тег выделения фона желтым маркером
<s> - перечеркивание;
<u> - подчеркивание;
<small> - уменьшенный шрифт, может также использоваться как внешний к блоку фрагмент
<sub> - подстрочный индекс, обычно для формул;
<sup> - верхний индекс, обычно для формул;
<math> - тег для написания формул, с помощью которого в HTML можно отображать математические формулы. Использует язык разметки MathML, предназначенный для машиночитаемого описания математических выражений. О языке MathML более подробней можно ознакомиться здесь.
<artikle> - тег артикля, который задает раздел контента, и образует независимую часть документа или сайта, например, статья в журнале, запись в блоге, комментарий.(не опробован)
<blockquote> - тег цитаты, применяется для больших цитат
<q> - тоже тег цитат;
<button> - Создает интерактивную кнопку. Элемент может содержать текст или изображение.
<pre> -(preformatted) - предварительно отформатированный - разрешает использование любого количества пробелов и переносов, так, как их ввел в код программист, например, в виде кода, стихов, или пространственной картинки. Но, если строка текста фиксированного формата не помещается в окне Web- обозревателя по ширине,то она ни в коем случае не будет переноситься.
<code> - браузеры не применяют к тексту внутри этого тега никакого форматирования, кроме font-family: monospace, и не подсвечивают синтаксис. Этот тег применяется вместе с тегом <pre>. Подсветка же кодов в браузерах HTML осуществляется с помощью других внешних библиотек, например, prism.js, или highlight.js. (Внимание, этот тег не пропускает угловые скобки и код html!)

В Google я задал поиск "словарь в html" и получил ответ от googleAI:
Для создания словаря, глоссария или списка пар «ключ-значение» в HTML используется специальный тег <dl>. Он состоит из контейнера списка, терминов <dt> и их определений <dd>. Это обеспечивает семантически правильную структуру, которую поисковики используют для метаданных.
Пример базового словаря:
html<dl>
<dt>HTML</dt>
<dd>Язык гипертекстовой разметки, используемый для создания структуры веб-страниц.</dd>

<dt>CSS</dt>
<dd>Каскадные таблицы стилей, отвечающие за внешний вид и оформление элементов на сайте.</dd>
</dl>
Нужно будет разобраться с этим инструментом!
