Таблицы

Таблица состоит из строк и столбцов и предназначена для структурирования данных.
В HTML для создания таблиц существует набор семантических тегов:
<table> - главный тег начала и окончания таблицы;
<thead> - отвечает за шапку таблицы. Внутри этого тега могут располагаться одна или более строк с заголовками таблицы. <thead> должен располагаться в разметке сразу за открывающим <tabl>, или после <caption>, но строго до <body>. Содержание тега публикуется над содержанием тега <caption> с выравниванием по левому краю таблицы и без переноса строк.
<caption> - тег наименованием таблицы и с характеристиками таблицы,также используется для сканридерa. Содержимое тега выравнивается по центру таблицы и переноcится по строкам.
<tbody> - Этот тег предназначен для основной части таблицы. Внутрь него помещаются строки с данными. Можно использовать несколько <tbody> внутри таблицы, разделяя тем самым данные на отдельные блоки;
<tfoot> - Тег нужен для строки «Итого» — некой строки с итогом данных таблицы. В таблице может быть только один блок <tfoot> ;
<th> - тег задает заголовки столбцов и отличается от <td> выравниванием заголовка по центру и выделением его жирным шрифтом;
<tr> - table row (ряд таблицы) - тег создания строк, по одному тегу на строку;
<td> - тег задающий данные ячейки в строке, вкладывается в тег <tr>. Сколько в ряду столбцов - столько ячеек. В HTML нет специального тега для столбцов;

Помимо глобальных атрибутов при работе с таблицами могут очень пригодиться атрибуты colspan и rowspan. Оба атрибута предназначены для объединения ячеек: colspan нужен для объединения ячеек из 2 или более столбцов, а rowspan для объединения ячеек из 2 или более рядов. При этом при заполнении ячеек нужно подсчитывать пропуски объединенных ячеек.

💡 У таблицы нет встроенных стилей для отображения границ ячеек. Для установки рамок таблицы используется CSS-свойство border.
💡 Ширина таблицы по умолчанию подстраивается под контент внутри, если не задавать дополнительные CSS-свойства.
Изначально, таблицы потребовались мне для написания текста на иностранном языке с переводом, Видимо, решение в виде таблиц для этого не подойдет и нужно изучить CSS.
